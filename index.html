Stream countdown

Shortcuts: Space starts or pauses, R resets. Checkerboard means transparent in OBS.

OBS setup. Add a Browser Source, paste the link, set 1920 × 1080. Leave "Local file" off.
For a timer that survives scene switches, turn off "Shutdown source when not visible", or use Count to clock time, which always shows the same deadline.
Start timer → Each time scene appears restarts the countdown whenever the scene goes live. No OBS refresh setting needed. For "Switch to scene when done", set the source's Page permissions to "Advanced access to OBS". Hover over the source in OBS Interact for −1/+1 min, pause and restart buttons.
For sound, set the source's audio to "Monitor and Output".
